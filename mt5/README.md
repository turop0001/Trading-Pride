
## v1.10 — свечи брокера для Пульта (вместо Yahoo)

Советник раз в минуту отправляет свечи M5/H1/D1 по 7 инструментам на `/api/feed`.
Пульт считает сигналы по ценам Tickmill. Если MT5 выключен дольше 20 минут в окне —
Пульт временно возвращается к Yahoo (GER40 — «нет данных»).

Настройки советника: `FeedKey` = ключ личного пульта (последняя часть адреса `/p/...`),
`FeedEnabled = true`. В «Сервис → Настройки → Советники» разрешить WebRequest для
`https://trading-pride-three.vercel.app`. MT5 должен работать в окнах 10:00–13:00 и 16:30–18:30 (Рига).
