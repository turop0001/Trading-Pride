# Движок аналитики Типа A (Пульт входа) — как пересчитать цифры

Это тот самый движок, на котором получены цифры аналитики в пульте (394 сделки, +356,7R, просадка −4R, серия SL 4 на 7 инструментах, БУ 80%).
Сохранён 17.10.2026, чтобы его можно было найти и запустить из любого аккаунта. Папка лежит в репозитории Trading-Pride (analytics_engine/) и копией на Маке: Work/Trading System/ДВИЖОК_АНАЛИТИКИ_Тип_A/.

## Что входит
- `rules_15717cd7e_394/` — правила Пульта (pult_rules.py, pult_s1.py, pult_ctx.py, analytics_gen.py) ровно на коммите 15717cd7e (16.10.2026 12:36), дающем 394 сделки. Коммит 78142f611 (14:10, FVG прошитый фитилём не блокирует вход) и позже дают БОЛЬШЕ сделок — это уже не база аналитики.
- `scripts/gen9rr.py` — прогон правил по истории: для каждого дня и инструмента анализ в 14:00 Риги по данным за 11 суток, сделка по сигналу, результат 1:2 без БУ.
- `scripts/an10_be80_и_сравнение.py` — пересчёт на БУ 80% (стоп на вход при 80% пути к цели 2R) и статистика (сделки, TP/БУ/SL, WR, ΣR, просадка по порядку входа, серия SL).
- `scripts/mk_an8.py`, `build_an.py`, `verify.py` — собирают карточки аналитики в web/private/pult.html (Тип A, A+C, по годам, по инструментам, по месяцам) и сверяют каждую строку страницы с данными.
- `results/` — готовые сделки: `pn_be80_7инстр_394.json` (база), `pn_be80_8инстр_422_с_AUDUSD.json` (текущая), `new3_..._be80.json` (AUDUSD, USDJPY, XAGUSD по отдельности), `pn_final_7инстр/` (сырой результат gen9rr), `TC_типC_1695.json` (Тип C).

## Как запустить (пример: проверить новый инструмент)
1. Данные: 5 лет M5 в `Work/Trading System/_bt/_data/<SYM>_5y_M5.csv.gz` (UTC; Dukascopy). Скрипт читает их из `~/d2w/<SYM>_5y_M5.csv.gz` — сделать там симлинки на файлы из _bt/_data.
2. Правила: взять checkout коммита 15717cd7e (`git worktree add ~/wt394 15717cd7e`), запускать ИЗ ЭТОЙ ПАПКИ (скрипт импортирует pult_rules и pult_ctx из текущего каталога).
3. Прогон: `cd ~/wt394 && RRX=2.0 S1FILE=$HOME/wt394/pult_s1.py OUTD=pn_new python3 gen9rr.py AUDUSD:2021 AUDUSD:2022 ... AUDUSD:2026` (ключ SYM:ГОД; результат в ~/pn_new/g9_SYM_ГОД.json; 8–10 секунд на инструмент-год). Файлы s1_new.py / s1_prod.py из старой папки скриптов НЕ подходят — они дают 0 сделок; нужен pult_s1.py из того же коммита.
4. БУ 80% и статистика: `python3 an10_be80_и_сравнение.py` (пути внутри — на ~/pn_v394 и результаты; поправить под свою папку).
5. Страница: `python3 mk_an8.py <путь к web/private/pult.html>` (в одной папке с pn_be80.json, TC.json, build_an.py), затем `python3 verify.py`, затем `cd web && node gen_html.js`.
6. Проверка воспроизводимости: на EURUSD 2024–2025 и GER40 2025 сделки и R совпадают с аналитикой на 100% (проверено 17.10.2026).

## Важное
- Без спреда и комиссий, вход по открытию свечи после триггера, цель 2R, закрытие 22:00 Риги.
- Мои тестовые прогоны другим скриптом (runabl/gen10: 498 и 450 сделок, просадка −5/−7R) НЕ равны аналитике; для сравнения с сайтом использовать только этот движок.
