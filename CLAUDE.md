# Правила работы с репозиторием Пульта (для любого аккаунта/чата Claude)

## 1. Правка страниц Пульта и страницы друга (ОБЯЗАТЕЛЬНО)
Сайт на Vercel собирается НЕ из `web/private/pult.html` и `friend.html`, а из сгенерированного `web/lib/html.js`.
После ЛЮБОЙ правки `web/private/*.html`:
1. `cd web && node gen_html.js`  (пересобирает `lib/html.js`)
2. проверить, что правка есть в `lib/html.js` (grep по уникальной строке изменения)
3. коммитить ВМЕСТЕ: `web/private/*.html` + `web/lib/html.js`
Без шага 1 правка не попадёт на сайт (случай 08.10.2026: порядок карточек «не менялся» из-за непересобранного html.js).
Любое изменение карточек делать в ОБЕИХ страницах (pult.html и friend.html).

## 2. Порядок карточек
Вход → Вынос → Наблюдаем → Скип/закрытые (ключ `_e` в `toLive`, затем окно, затем тикер).

## 3. Пуши и деплой
Не пушить каждую мелкую правку: копить минимум 5 правок или пушить по прямой команде Дмитрия. Следить за лимитом Vercel (~90% за 24 ч — предупредить). Файлы без подтверждения не менять.

## 4. Workflows GitHub
Файлы `.github/workflows/*` инструмент коммита не принимает: класть временно в корень и переносить `mv` через оболочку Mac.

## 5. Сторож цикла
`web/pages/api/feed.js` (MT5 → Vercel каждую минуту) запускает `loop.yml`; запасной путь `repository_dispatch: pult-loop`; диагностика в ветке `feed`, `live.json` поле `wd`.

- Цикл `pult_loop.py` тикает каждые 20 с (раньше 60), кэш фида `live_check._feed` 15 с, `/api/state` кэш 8 с, страница опрашивает раз в 10 с.

## 7. Аналитика сделок (11.10.2026)
- Вкладка «Аналитика сделок» в личном Пульте (не на странице друга): последние 10 сделок Типа A и последние 10 Типа C, графики M5 и H1 с разметкой (бокс, вынос, вход/стоп/цель, FVG, ликвидность) и сводка.
- Данные: `state/analytics.json` ({"A":[...],"C":[...]}); пишет `analytics_gen.py` из `pult_tick.py` при закрытии сделки (хуки `add_closed`), старая запись вытесняется (KEEP=10); файл входит в `FILES` в `state_sync.py`; первичное заполнение — `seed_analytics.py` (повтор движком).
- Сайт: `/api/analytics` (GET из ветки state), `/api/acomments` (GET/POST, файл `state/ac_comments.json` в main), библиотека графиков `web/public/ac.js` + `ac.css` (всё под классом `.acx`).
- Комментарии пишутся на вкладке, разбор по запросу делает Claude в чате: читает `state/ac_comments.json` и сверяет с записью в analytics.json (id = тип_пара_день).
- Те же графики показываются вместо PNG-скринов в «Истории», «Журнале» и карточках «Чек-листа» (`window.acShot` в pult.html, подмена после загрузки; если записи нет в analytics.json — остаётся старый PNG или строка скрывается).
- Фавикон — логотип TP: `web/public/icon.svg`, `icon-32/180/192/512.png`.
- После правки pult.html — `cd web && node gen_html.js`, коммитить вместе.
