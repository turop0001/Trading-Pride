# Пульт входа — автономный тик-бот

Полностью независимая от Claude/аккаунта/сессии версия торгового Пульта (FundingPips $25,000,
Тип A «Азия→Франкфурт/Лондон», Тип C «Лондон→NY»). Работает через GitHub Actions по расписанию,
шлёт уведомления напрямую в Telegram. Правила и код — перенос боевой версии из claude.ai Project
«Trading PRO» на 29.09.2026 (v77: Тип A — правила v76 без изменений, Тип C — реактивный bias +
engulf-выкуп, nyscan3-логика).

## Как это работает

- `.github/workflows/tick.yml` — расписание (cron) каждые 5 минут в торговые окна (с запасом на
  переход летнего/зимнего времени), плюс ручной запуск (`workflow_dispatch`).
- Каждый запуск: подтягивает свежие цены через `yfinance`, прогоняет `pult_rules.analyze()`
  (полные правила), шлёт в Telegram только при изменении статуса или новом сигнале, сохраняет
  состояние в `state/pult_state.json` и коммитит его обратно в репозиторий — так прогресс
  переживает между запусками, хотя каждый запуск стартует с чистого контейнера.
- Источник цен — `yfinance` (Pepperstone/синтетика), не TradingView и не браузер: задержка
  обычно 5-20 минут, XAUUSD идёт через PAXG-USD (см. комментарии в `live_check.py`).
- GER40 не автоматизирован (не было надёжного круглосуточного источника цены на yfinance) —
  всегда показывает «смотреть вручную».

## Настройка секретов (один раз)

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
- `TG_BOT_TOKEN` — токен Telegram-бота.
- `TG_CHAT_ID` — id чата/канала.
- `TG_THREAD_ID` — необязательно, id топика форума, если чат с топиками.

## Файлы

- `pult_rules.py` — правила Типа A и Типа C (движок).
- `live_check.py` — источник данных (yfinance), нарратив тренда H1(7д)/D1(14д), сборка данных
  для дашборда (`state/pult_docs/*.json`).
- `notify.py` — форматирование и отправка сообщений в Telegram.
- `pult_tick.py` — точка входа одного тика (запускается workflow'ом).
- `state/` — состояние между запусками (коммитится автоматически ботом).

## Проверить руками

**Actions → Pult tick → Run workflow** — запускает тик прямо сейчас, вне расписания (полезно
для проверки после изменения кода или секретов).
