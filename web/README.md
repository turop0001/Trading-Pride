# Пульт — Vercel-дашборд

Читает `state/pult_state.json` из этого же GitHub-репозитория (тот файл, что коммитит
GitHub Actions после каждого тика) и показывает карточки инструментов + отчёт дня.
Две страницы:

- `/` — полный дашборд (цена, боксы, тренд H1/D1).
- `/friend` — упрощённая страница для друга (только статус/направление по инструменту
  и отчёт дня, без технических деталей).

Обе страницы опрашивают `/api/state` раз в 30 секунд — обновляются сами, без перезагрузки.

## Деплой на Vercel (один раз)

1. **New Project** → импортировать репозиторий `turop0001/Trading-Pride`.
2. **Root Directory** — указать `web` (важно: приложение лежит в подпапке, не в корне репозитория).
3. **Environment Variables**:
   - `GH_TOKEN` — GitHub-токен с правом чтения этого репозитория (Contents: Read), можно
     fine-grained PAT только на этот репозиторий.
   - `GH_REPO` — необязательно, по умолчанию `turop0001/Trading-Pride`.
4. Deploy — дальше Vercel сам передеплоивает при каждом пуше в `main` (в т.ч. когда
   GitHub Actions коммитит новый `state/pult_state.json`), плюс страницы сами опрашивают
   API раз в 30 сек, так что обновление видно без ручного редеплоя.

## Локальный запуск

```bash
cd web
npm install
GH_TOKEN=... GH_REPO=turop0001/Trading-Pride npm run dev
```
